🔥 FireAI API

OpenAI-совместимый API. Подключайте FireAI к любым клиентским библиотекам.

Чтобы управлять ключами, войдите в аккаунт в основном приложении.

Ваши API-ключи

Ключ даёт доступ к API от имени вашего аккаунта. Секрет показывается здесь же — храните его в безопасности.

Быстрый старт

Все запросы: Authorization: Bearer sk-fireai-…

curl
curl http://localhost:3000/v1/chat/completions \
  -H "Authorization: Bearer sk-fireai-ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "Привет!"}]
  }'
python (openai sdk)
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="sk-fireai-ВАШ_КЛЮЧ",
)

response = client.chat.completions.create(
    model="fireai-demo",
    messages=[{"role": "user", "content": "Напиши песню"}],
)
print(response.choices[0].message.content)
python — стриминг
stream = client.chat.completions.create(
    model="fireai-demo",
    messages=[{"role": "user", "content": "Привет"}],
    stream=True,
)
for chunk in stream:
    piece = chunk.choices[0].delta.content
    if piece:
        print(piece, end="", flush=True)
javascript
const res = await fetch("http://localhost:3000/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: "Bearer sk-fireai-ВАШ_КЛЮЧ",
  },
  body: JSON.stringify({
    messages: [{ role: "user", content: "Сделай 3D игру" }],
    stream: false,
  }),
});
const data = await res.json();
console.log(data.choices[0].message.content);

Эндпоинты

POST /v1/chat/completions — чат-модель. Поле stream: true включает SSE-стриминг в формате OpenAI.

GET /v1/models — список доступных моделей.
